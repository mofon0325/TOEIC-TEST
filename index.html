自己的英文題庫｜題目與答案分頁｜本機保存與備份

資料會自動儲存在此瀏覽器。清除網站資料或更換裝置可能遺失紀錄，請定期匯出 JSON 備份。匯入會覆蓋目前全部資料。

題目管理

批次匯入題目

貼入 JSON 題目陣列，一次建立整份 59 題；亦支援純文字選擇題（題號. 題目，下一行 A. 至 D.）。匯入會加入目前練習日，不覆蓋原有題目。

支援單選題、翻譯／申論、閱讀文章。可貼上完整文章，或逐題編輯。每個練習日的題數可自由增減。

答案與解析

答案與作答分開儲存。可以自行輸入正解與詳解，或請 ChatGPT 批改後貼回這裡。選擇題輸入正解後會自動計分。

單字庫與複習

自己新增不會的單字，或從題目標記後整理。所有單字與複習進度都包含在 JSON 備份中。
